# Games

A game in LEADR groups all your boards, scores, and settings together. Create one game for each game you ship.

## Game ID

Each game has a unique identifier in the format `gam_<uuid>`, for example: `gam_a1b2c3d4-e5f6-7890-abcd-ef1234567890`.

You'll need your Game ID when configuring the LEADR SDK in your game code. Find it in the LEADR app by navigating to **Games**, selecting your game, and pressing `y` to copy the ID.

## Slug

Each game has a "slug" that is globally unique. Slug is autogenerated from the game name, but can be manually specified if you need.

**Example:** For a game with the name "Pong 2026", the generated slug would be `pong-2026`, but you could specify the slug as just `pong` if you preferred and that slug was not already used by another game.

A game's slug is used for the URL for that game's web page which lists the published boards. E.g. for a game with slug `pong`, the web page would have the URL `https://leadr.gg/games/pong`.


## Fields

| Field | Required | Example | Default | Description |
|-------|----------|---------|---------|-------------|
| **Name** | Yes | `Pong 2026` | - | Your game's title |
| **Slug** | Yes | `pong-2026` | Auto-generated | URL-friendly identifier (2-50 characters, lowercase letters, numbers, and hyphens) |
| **Description** | No | `Classic pong with a twist` | None | A brief description of your game |
| **Tags** | No | `arcade, multiplayer` | None | Comma-separated tags for organization |
| **Steam App ID** | No | `123456` | None | Your game's Steam App ID if published on Steam |
| **Page URL** | No | `https://example.com/pong` | None | Link to your game's external website or store page |
| **Anti-Cheat** | No | - | Enabled | Toggle to enable LEADR's anti-cheat system |

### Slug Format

The slug is used in board page URLs and must follow this format:

- 2-50 characters
- Lowercase letters (`a-z`) and numbers (`0-9`)
- Hyphens (`-`) allowed between words, but not at the start or end
- Must be globally unique across all LEADR games

**Examples:** `space-blaster`, `my-awesome-game`, `puzzle2048`

If you don't provide a slug, LEADR auto-generates one from your game name.

## Anti-Cheat

Anti-cheat is enabled by default for new games. When enabled, LEADR automatically flags suspicious score submissions for your review. You can toggle this setting when creating or editing a game.

See the [Anti-Cheat reference](./anti-cheat.md) for details on how the system detects suspicious scores.

See [Review Score Flags](../guides/review-score-flags.md) to learn how to review and remove flagged scores in the LEADR app.
