# Godot SDK

The LEADR Godot SDK is a native GDScript plugin that lets you integrate LEADR leaderboards directly into your Godot Engine game. Install the plugin, configure your API key, and submit scores with a few lines of GDScript — no raw HTTP requests needed. Check out the [GitHub repository](https://github.com/LEADR-official/leadr-sdk-godot) for source code and releases.
