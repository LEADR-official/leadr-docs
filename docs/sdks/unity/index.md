# Unity SDK

The LEADR Unity SDK is a native C# package that lets you integrate LEADR leaderboards directly into your Unity game. Import the package, configure your API key, and submit scores with a few lines of C# — no raw HTTP requests needed. Check out the [GitHub repository](https://github.com/LEADR-official/leadr-sdk-unity/) for source code and releases.
